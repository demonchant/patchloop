GET YOUR RUNNER READY

One site.
Your own runner.

PatchLoop keeps the session and run record online. Kane, Codex, browser sessions, source code, and worktrees stay on the computer you pair.

01

Install your tools

Use Node.js 20 or newer, Git, and Chrome on the computer that will run the checks.

npm install -g @testmuai/kane-cli @openai/codex
kane-cli login --oauth
codex login

Confirm your Kane account has credits and Codex is signed in before starting a demo.

02

Prepare the target app

The target and PatchLoop are separate Git checkouts. Clone the supplied showcase target on the runner computer, then commit its reviewed baseline.

git clone https://github.com/demonchant/patchloop-full-showcase2.git
cd patchloop-full-showcase2
npm start

The manifest's local start command executes with your user permissions. Read it before registering this repository.

03

Pair and choose

Set the target path in the runner terminal before starting or pairing.

$target = Join-Path $HOME 'patchloop-full-showcase2'
$env:PATCHLOOP_TARGET_REPO = (Resolve-Path $target).Path
npm run worker -- --url https://YOUR-PATCHLOOP-URL --pair-code YOUR-ONE-TIME-CODE

Use the exact command shown after generating a one-time code in the signed-in PatchLoop page. Keep it private; omit the code on later restarts.

BEFORE A RUN

Check the target baseline.

PatchLoop uses the target's committed HEAD and creates an isolated worktree. Uncommitted target files are not copied. Review `patchloop.target.json` before registering a repo: its install and start commands run locally with your operating-system permissions.

LOCAL-ONLY OPTION

Run the app and tools on one computer.

npm ci
$env:PATCHLOOP_TARGET_REPO = (Resolve-Path 'C:\path\to\trusted-target').Path
npm start

Open http://127.0.0.1:4173. In local mode, run history and worktrees stay under `.patchloop/`. The target needs a committed Git baseline before PatchLoop can select it.
